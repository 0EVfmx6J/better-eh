# Better EH

给 E-Hentai、ExHentai 和 nHentai 用的浏览和阅读脚本。

## 功能

- 画廊列表可以切换网格和列表，往下滑会自动加载下一页。
- 搜索框支持中文标签联想，点详情页的标签也能加到搜索框。
- 可以批量加入稍后阅读，或批量删除浏览历史和稍后阅读里的记录。阅读进度按站点保存在当前浏览器里。
- 阅读时上下滑动翻页，拖进度条跳页。「稍后阅读」点「全部阅读」可以按顺序连着看。
- 支持浅色和深色主题。

## 安装和使用

[下载 better-eh.user.js](https://github.com/0EVfmx6J/better-eh/releases/latest/download/better-eh.user.js)

- 桌面用 Tampermonkey。装好扩展后，打开上面的链接并点安装。
- iPhone 或 iPad 用 Userscripts。在 Safari 启用扩展并允许它访问站点，再把下载的脚本放进 Userscripts 的脚本目录。

装好后刷新站点页面即可。手机上阅读时点一下页面可以显示菜单和进度条，再点一下收起。

用「打开原站」可以切回原站页面。点原站右上角的拉环，就能回到 Better EH。
